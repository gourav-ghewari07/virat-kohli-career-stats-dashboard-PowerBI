🏏 Virat Kohli Career Statistics Dashboard

📌 Project Overview

The Virat Kohli Career Statistics Dashboard is an interactive Power BI project designed to analyze the batting performance of one of the world's greatest cricketers, Virat Kohli.

The dashboard provides comprehensive insights into his career statistics across Test, ODI, and T20 formats using key performance indicators, batting records, and scoring patterns.

This project demonstrates how Power BI can be used to transform sports data into meaningful visual insights for performance analysis.

---

🎯 Project Objectives

The main objectives of this project are:

- Analyze Virat Kohli's overall batting performance.
- Compare statistics across cricket formats.
- Visualize scoring patterns and milestones.
- Evaluate consistency through averages and strike rates.
- Identify performance trends using interactive dashboards.

📈 Dashboard Features

Career Performance Overview

Provides a summary of:

- Total Runs
- Total Innings
- Batting Average
- Strike Rate

Format-wise Analysis

Compare statistics across:

- Test Cricket
- One Day Internationals (ODI)
- Twenty20 Internationals (T20)

Batting Milestones

Visual representation of:

- Total Centuries (100s)
- Total Half Centuries (50s)

Boundary Analysis

Analyzes scoring distribution through:

- Fours
- Sixes

Balls Faced and Dot Ball Analysis

Measures:

- Total Balls Faced
- Dot Ball Percentage

to understand batting style and scoring efficiency.

Innings vs Dismissals

Compares:

- Total Innings Played
- Total Outs

to evaluate consistency and reliability.

Highest Score Analysis

Displays highest individual score across different formats.

---

🔍 Key Insights

1. Exceptional Career Consistency

Virat Kohli has accumulated over 28,000 runs with an average exceeding 50, demonstrating remarkable consistency throughout his career.

2. Strong Strike Rate

A strike rate of approximately 92 highlights his ability to balance aggression with consistency.

3. Significant Milestone Achievements

The dashboard shows a large number of centuries and half-centuries, reflecting his ability to convert starts into major scores.

4. Boundary-Driven Scoring

Fours contribute a substantial portion of his boundary runs, indicating a technically strong batting style.

5. Highest Scores Differ Across Formats

Performance varies by format, with Test cricket showing the highest individual score among formats.

6. Low Dismissal Frequency

The comparison between innings and outs highlights his ability to remain at the crease and build innings.
